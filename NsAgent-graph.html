v0.3.0 — 函数详情 — NEW 新增 MOD 修改

core（新增）

core/prompt.py NEW
build_prompt(skills_text="")
组装分层 System Prompt：身份/工具/规则/安全四层，支持技能内容动态注入。
core/context.py NEW
count_tokens(text)
粗略估算 token 数（中文 2 字符/token，英文 4 字符/token）。
compress(messages, max_tokens, keep_last)
对话超限时自动将中间消息压缩为摘要，保留 system + 摘要 + 最后 N 条。

skills（新增）

skills/registry.py NEW
register_skill(name, trigger, description, content)
注册技能，trigger 用 | 分隔多关键词。
match_skills(user_input)
根据用户输入匹配已注册技能。
inject_skills(messages, matched)
将匹配技能的内容注入 System Prompt。
skills/finance.py NEW
(模块顶层)
注册"财报分析"技能：触发词=营收/利润/年报等，注入财报分析规范。

tools/finance（新增）

tools/finance/market_data.py NEW
get_stock_price(code)
调用 akshare 查 A 股实时行情：最新价、涨跌幅、成交量、成交额。
tools/finance/financial_report.py NEW
financial_report(stock_name)
多指标并行搜索年报：营收/净利润/增长率/每股收益，去重后返回结构化数据。
