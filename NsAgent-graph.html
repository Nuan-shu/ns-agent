core

core/agent.py — Agent 核心循环
run(messages=None)
Agent 主循环 — 发送消息给 DeepSeek LLM，有 tool_calls 就执行工具并继续循环，否则输出回复并结束。是整个 Agent 的心跳机制。
入: messages: list[dict] | None 出: None — 直接 print 输出
-> tools/registry.py get_tool_definitions()
-> tools/registry.py execute(name, args)
chat()
交互式 REPL — 读取用户输入 -> 追加到 messages -> 调用 run() -> 循环，支持 /exit 退出。
入: 无 — 从 stdin 逐行读取 出: None
-> core/agent.py run(messages=...)

tools

tools/registry.py — 工具注册表（中心枢纽）
register(name, definition, handler)
注册一个工具到全局注册表 _registry。工具模块在 import 时自动调用此函数报到，Agent Loop 无需知道具体工具有哪些。
入: name: str | definition: dict | handler: callable 出: None — 写入全局 _registry 字典
<- 被调用: time_tool.py, file_tools.py(x2), terminal_tool.py, search_tool.py
get_tool_definitions()
返回所有已注册工具的 definition 列表，拼给 LLM 的 tools 参数。
入: 无出: list[dict]
<- 被 core/agent.py run() 调用
execute(name, args)
根据工具名查表，调用对应 handler 函数。查不到则返回错误字符串（永不抛异常）。
入: name: str | args: dict出: str
<- 被 core/agent.py run() 调用
tools/search_tool.py — 知识库搜索工具
search_knowledge(query)
Agent 面向 LLM 的工具函数 — 调用 knowledge.search 做多源联合搜索（年报 + Agent 文档），返回格式化文本。
入: query: str出: str — 格式化搜索结果
-> knowledge/search.py search_formatted(query)
-> tools/registry.py register("search_knowledge", ...)
tools/file_tools.py — 文件读写工具
read_file(path, offset=1, limit=200)
读取文件内容，返回带行号的文本。支持 ~ 展开、偏移量控制和行数限制。
入: path: str | offset: int=1 | limit: int=200出: str
-> tools/registry.py register("read_file", ...)
write_file(path, content)
覆盖写入文件内容，自动创建父目录。
入: path: str | content: str出: str
-> tools/registry.py register("write_file", ...)
tools/terminal_tool.py — 终端命令执行
run_command(command, timeout=30)
在 ns-agent 项目目录下执行 shell 命令（subprocess.run），返回 stdout + stderr 合并。
入: command: str | timeout: int=30出: str
-> tools/registry.py register("terminal", ...)
tools/time_tool.py — 时间工具
get_current_time()
返回当前日期时间字符串，让 Agent 知道「现在」是什么时候。
入: 无出: str — "2026-06-11 14:30:00"
-> tools/registry.py register("get_current_time", ...)

knowledge

knowledge/search.py — 统一多源搜索
unified_search(query, top_k=5)
用 bge-small-zh-v1.5 将 query 编码为向量，并行查询 ChromaDB 二源（annual_reports 1683块 + agent_engineering 27块），按 cosine 距离合并排序返回。
入: query: str | top_k: int=5出: list[dict]
（调用外部库: chromadb, sentence_transformers）
search_formatted(query, top_k=5)
对 unified_search 结果做格式化，每条结果标注来源（年报/Agent工程）、距离分数、内容摘要。
入: query: str | top_k: int=5出: str
-> knowledge/search.py unified_search(query, top_k)

core/agent.py MOD — Agent 核心循环
v0.2.0 改动：接入会话持久化 + API 重试 + 统一错误处理；新增 /new 命令；/exit 输出 session_id
run(messages=None, session_id=None) MOD
Agent 主循环 — 通过 call_with_retry 调用 DeepSeek LLM（指数退避重试），有 tool_calls 就执行工具并同步保存到 SQLite 会话，否则输出回复并结束。
入: messages: list[dict] | None | session_id: str | None 出: None — 直接 print 输出
-> tools/registry.py get_tool_definitions() / execute()
-> core/retry.py call_with_retry() NEW
-> memory/session.py save_message() NEW
chat() MOD
交互式 REPL — 启动时自动 init_db() + 24h 内自动恢复上次会话；新增 /new 命令开始全新会话；/exit 输出 session_id 供追溯。
入: 无出: None
-> core/agent.py run(messages, session_id)
-> memory/session.py init_db / get_last_session / create_session / save_message NEW
-> core/errors.py NsAgentError NEW
core/retry.py NEW — API 重试机制
call_with_retry(fn, *args, **kwargs)
指数退避重试包装器 — 最多 3 次重试（1s -> 2s -> 4s）。只重试可恢复错误（APIConnectionError / APITimeoutError / RateLimitError / InternalServerError），400/401 直接抛出。
入: fn: callable + 透传参数出: fn 的返回值
（调用外部库: openai, time）
core/errors.py NEW — 统一异常体系
NsAgentError(message, code=None, details=None)
NsAgent 异常基类 — 支持错误码（code）和额外上下文（details），提供 to_dict() 统一序列化。子类：APIError / ToolError / ConfigError。
入: message: str | code: str | None | details: dict | None出: Exception
子类: APIError / ToolError / ConfigError
